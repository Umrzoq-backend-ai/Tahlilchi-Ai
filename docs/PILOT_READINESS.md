# Pilotga tayyorgarlik holati

2026-09-28 holatidagi lokal prototip: hisobga kirish, CSV/XLSX yuklash, profiling, tayyor tahlil, Gemini agent, grafik, tarix va natijaning xavfsiz CSV/JSON eksporti ishlaydi. Alohida bo‘sh bazada login → namuna upload → oylik hisob → grafik → eksport → tarix → o‘chirish brauzer oqimi o‘tdi. Google OAuth bilan bog‘langan mavjud hisob va unga tegishli fayllar o‘qildi; mavjud SQLite bazasining `integrity_check` natijasi `ok`, foreign key xatosi 0, yuklangan fayllar mavjud. Ikkala saqlangan dataset profili yangi versiyaga yangilandi. Tekshiruv paytida saqlangan 5 agent ishining 4 tasi `needs_input` edi: ulardan bir nechtasi `order_date` sana formatini qayta so‘ragan. Endi profil barcha bo‘sh bo‘lmagan qiymatlar `YYYY-MM-DD` ekanini tekshirsa, format agentga faqat metadata sifatida uzatiladi va interfeysda ko‘rsatiladi. Eski fayl profili birinchi ochilganda avtomatik yangilanadi; qayta yuklash kerak emas. Noaniq yoki aralash sana formatida taxmin qilinmaydi.

Backend testlari: 111/111 o‘tdi; Ruff, frontend TypeScript va production build o‘tdi. Alohida test bazasidagi brauzer sinovi desktop/mobil oqimni tasdiqladi. Haqiqiy Gemini bilan sana formati yozilmagan **bitta** sintetik savolning planner rejasigina emas, kod yaratish → OS sandbox → mustaqil reference tekshiruvi → brauzerdagi natija ham o‘tdi. Bu bitta end-to-end holat butun savollar to‘plamining aniqligini isbotlamaydi. 15 ta sintetik holatdan 14 ta lokal hisob/rad etish tekshirildi (14/14); prognoz holati AI rad etish siyosati uchun. To‘liq live planner baholashi, kvota/xarajat va real kompaniya savollari bo‘yicha o‘lchov hali yakunlanmagan.

Kompaniya pilotidan oldin zarur ishlar: real KPI va ustun ta’riflarini belgilash; anonimlashtirilgan kompaniya savollari uchun reference javoblarni tekshirish; Gemini kvota/xarajatini o‘lchash; uzoq ishlarni server restartida yo‘qotmaydigan queuega ko‘chirish; umumiy jamoa ma’lumotlari va ruxsatlarini loyihalash; parser/sandbox va deploymentni kompaniya muhitida mustahkamlash. Shu sabab hozirgi holat ishlaydigan **lokal demo**, ommaviy production emas.
