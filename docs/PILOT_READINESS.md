# Pilotga tayyorgarlik holati

2026-09-28 holatidagi lokal prototip: hisobga kirish, CSV/XLSX yuklash, profiling, tayyor tahlil, Gemini agent, grafik, tarix va natijaning xavfsiz CSV/JSON eksporti ishlaydi. Alohida bo‘sh bazada login → namuna upload → oylik hisob → grafik → eksport → tarix → o‘chirish brauzer oqimi o‘tdi. Google OAuth bilan bog‘langan mavjud hisob va unga tegishli fayllar o‘qildi; mavjud SQLite bazasining `integrity_check` natijasi `ok`, foreign key xatosi 0, yuklangan fayllar mavjud. Avval yuklangan dataset profillari yangi versiyaga yangilandi. Oldingi agent ishlarining ayrimlari `order_date` sana formatini qayta so‘ragan. Endi profil barcha bo‘sh bo‘lmagan qiymatlar `YYYY-MM-DD` ekanini tekshirsa, format agentga faqat metadata sifatida uzatiladi va interfeysda ko‘rsatiladi. Eski fayl profili birinchi ochilganda avtomatik yangilanadi; qayta yuklash kerak emas. Noaniq yoki aralash sana formatida taxmin qilinmaydi.

Backend testlari: 114/114 o‘tdi; Ruff, frontend TypeScript va production build o‘tdi. Alohida test bazasidagi brauzer sinovi desktop/mobil oqimni tasdiqladi. Haqiqiy Gemini bilan sana formati yozilmagan **bitta** sintetik savolning planner rejasigina emas, kod yaratish → OS sandbox → mustaqil reference tekshiruvi → brauzerdagi natija ham o‘tdi. Bu bitta end-to-end holat butun savollar to‘plamining aniqligini isbotlamaydi. 16 ta sintetik holatdan 15 ta lokal hisob/rad etish tekshirildi (15/15); prognoz holati AI rad etish siyosati uchun. To‘liq live planner baholashi, kvota/xarajat va real kompaniya savollari bo‘yicha o‘lchov hali yakunlanmagan.

Kompaniya pilotidan oldin zarur ishlar: real KPI va ustun ta’riflarini belgilash; anonimlashtirilgan kompaniya savollari uchun reference javoblarni tekshirish; Gemini kvota/xarajatini o‘lchash; uzoq ishlarni server restartida yo‘qotmaydigan queuega ko‘chirish; umumiy jamoa ma’lumotlari va ruxsatlarini loyihalash; parser/sandbox va deploymentni kompaniya muhitida mustahkamlash. Shu sabab hozirgi holat ishlaydigan **lokal demo**, ommaviy production emas.

Raqamlangan savollar (`1.`, `2.`, `3.`) endi brauzerda alohida run sifatida ketma-ket bajariladi; har natija alohida ko‘rinadi. Bo‘sh kataklar va aynan takroriy qatorlar uchun bitta `quality` amali qo‘shildi. Uch savolli haqiqiy Gemini brauzer sinovi bir marta to‘liq o‘tdi; keyingi takroriy sinovda dastlabki ikki savol o‘tib, uchinchisi provayderning `AI_QUOTA` limiti bilan to‘xtadi. Bu live baholashda kvota hali real cheklov ekanini ko‘rsatdi. Navbat UI xotirasida turadi; sahifa yopilsa yuborilmagan savollar avtomatik tiklanmaydi.
