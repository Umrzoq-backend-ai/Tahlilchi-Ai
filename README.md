## ⚡ Asosiy Imkoniyatlar

1. **Ro‘yxatdan o‘tish va to‘lov talab etilmaydi**:
   - Akkaunt ochish yoki bank kartasini ulash shart emas.
   - Har qanday foydalanuvchi o‘zining bepul Google AI Studio kaliti bilan cheksiz foydalana oladi.
2. **Keng qamrovli media qo‘llab-quvvatlashi**:
   - 🎬 **Video**: MP4, WEBM, MOV (katta hajmdagi videolarni AI uchun avtomatik optimallashtirish bilan)
   - 📺 **YouTube**: To‘g‘ridan-to‘g‘ri YouTube havolasi orqali to‘liq transkript va video tahlili
   - 🎙️ **Audio**: MP3, WAV, M4A, OGG, FLAC
   - 📄 **PDF Hujjatlar**: Kitoblar, ilmiy maqolalar, taqdimotlar va hisobotlar
3. **7 xil ixtisoslashgan tahlil rejimlari**:
   - 💼 **Uchrashuv bayonnomasi**: Qarorlar, vazifalar va spikerlar bo‘yicha vaqt taqsimoti
   - 📰 **Yangiliklar & Fakt-chek**: Faktlar tekshiruvi, xolislik darajasi va hissiy manipulyatsiya filtri
   - 🎓 **Ta’lim & Dars konspekti**: Qisqa konspekt, asosiy qoidalar va interaktiv 4 variantli test
   - 👶 **Bolalar xavfsizligi**: 1-16 yosh chegarasi, zararli sahnalar ogohlantirishi va ota-onalar uchun tavsiya
   - 👥 **Intervyu & HR bahosi**: Nomzod bilimi, kuchli/zaif tomonlari va 100 ballik moslik reytingi
   - 🎤 **Notiqlik & Taqdimot (3V)**: Verbal, Vizual va Vokal tahlili
   - 📑 **PDF & Hujjat tahlili**: Tezislar, jadval/statistika tahlili va amaliy tavsiyalar
4. **To‘liq O‘zbekcha Transkript & Diarizatsiya**:
   - Boshqa tildagi videolarda ham har bir spikerning aytgan gaplari va ularning ravon o‘zbekcha tarjimasi qadamma-qadam chiqariladi.
5. **Vaqt belgilari bilan interaktiv video chat**:
   - Video yuzasidan bevosita savol-javob qilish va bosganda kerakli daqiqaga o‘tish.

## 🛠 Texnologiyalar Steki

- **Frontend:** Next.js 15 (App Router), React 19, Tailwind CSS, Lucide Icons
- **Backend:** Next.js Serverless Functions (`/api/analyze`, `/api/chat`)
- **Sun’iy Intellekt:** Google Gemini 2.5 Flash, Gemini 2.5 Pro, `@google/genai` SDK
- **Deploy:** Vercel Production (`edge` & `serverless`)

## 💻 Mahalliy Kompyuterda Ishga Tushirish

```bash
# 1. Repozitoriyani klonlash
git clone https://github.com/Umrzoq-backend-ai/Tahlilchi-Ai.git
cd Tahlilchi-Ai

# 2. Bog'liqliklarni o'rnatish
npm install

# 3. Dasturchi rejimida ishga tushirish
npm run dev
```

Brauzeringizda [http://localhost:3000](http://localhost:3000) manzilini oching.
